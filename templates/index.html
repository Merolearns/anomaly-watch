How it works

For each point, the baseline is the mean and standard deviation of the previous window points only. A point is flagged when it sits at least the threshold number of standard deviations from that baseline. Using previous points only means no lookahead: the detector never peeks at the future, so it behaves the same on live data as on history.

API: POST /api/analyze with JSON {"values": [...], "window": 20, "threshold": 3.0}.
